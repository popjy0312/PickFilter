# PickFilter

페이지에서 조회수·댓글수 숫자를 직접 선택하고, 지정한 최소값 이상인 게시글만 남기는 크롬 확장 프로그램 샘플입니다.

## 설치

1. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 프로젝트 폴더를 선택합니다.
3. 게시판을 열고 확장 프로그램 메뉴에서 **PickFilter**를 클릭합니다.

별도 빌드나 패키지 설치는 필요 없습니다. 일반 웹페이지에서 사용하세요. Chrome 내부 페이지 등 실행 불가 페이지에서는 아이콘에 `!`가 표시됩니다.

## Android에서 설치

Edge Canary용 **CRX 설치 파일**도 제공합니다. 릴리스에서 `PickFilter-Android-CRX-v0.1.7.zip`을 내려받아 압축을 푼 뒤 설치하세요. [Android 설치 안내](INSTALL-ANDROID.md)를 참고하세요. 현재 Android 실기기 동작은 미검증입니다.

## 사용

1. **숫자 항목 선택**을 누르고 게시글에 표시된 조회수 또는 `[74]` 같은 댓글수 표시를 클릭합니다. Esc로 취소할 수 있습니다.
2. 파란 테두리가 게시글 전체를 감싸는지 확인합니다. 숫자 칸만 선택되거나 너무 넓게 잡혔다면 **범위 넓히기 / 좁히기**로 조정합니다.
3. 미리보기에서 여러 게시글의 숫자가 맞는지 확인하고 **이 범위 확정**을 누릅니다.
4. 최소값(예: 조회수 `1,000`, 댓글수 `50`)를 입력하고 **적용**을 누릅니다. 기준과 같은 숫자도 남깁니다.
5. **필터 해제**로 원래 목록을 복원합니다. 패널을 닫아도 적용된 필터는 유지되며, 확장 아이콘을 누를 때마다 패널 표시/숨김이 전환됩니다. 페이지를 열거나 이동할 때는 패널을 자동으로 띄우지 않습니다. 오류 안내도 아이콘을 눌러 패널을 열면 확인할 수 있습니다.

## 숫자 입력 중 사이트 단축키 충돌 (v0.1.4)

패널에서 숫자를 입력할 때 키보드·입력 이벤트가 페이지의 일반 단축키 처리기로 전달되지 않도록 차단합니다. 숫자 편집의 기본 동작과 패널 밖의 사이트 단축키는 유지합니다.

## 인기글 댓글수 필터 (v0.1.2)

인기글 페이지에서 **숫자 항목 선택 → `[74]` 같은 댓글수 클릭 → 게시글 전체 범위 확인 → 이 범위 확정 → 최소값 입력 → 적용** 순서로 사용하세요. 예를 들어 `50`을 입력하면 댓글수 50 이상인 게시글을 남깁니다. 댓글수가 표시되지 않은 글은 판독 불가로 유지합니다. 제목 전체를 클릭하지 말고 대괄호 숫자 표시를 선택하세요.

조회수와 댓글수 중 선택한 한 항목을 필터링합니다. 같은 URL 범위에서 항목을 다시 선택하고 적용하면 이전 설정을 교체합니다. 인기글의 정렬 조건은 별도 설정 범위이며 해당 인기글 목록에서 한 번 설정하면 다음 페이지에도 유지됩니다.

## 설정 유지 (v0.1.1)

- **적용**을 누르면 선택한 조회수 위치와 최소 조회수가 저장됩니다.
- `/board`, `/board?page=2`는 같은 게시판 설정을 사용합니다. 페이지 번호(`page`)와 URL 해시는 무시하고, 다른 경로·검색 조건은 구분합니다.
- **필터 해제**는 저장한 위치와 기준은 유지하고 자동 필터만 끕니다. 다시 **적용**하면 켜집니다.
- 사이트 상시 접근 권한이나 자동 실행 대상 도메인은 지정하지 않습니다. 아이콘을 눌러 현재 탭의 임시 접근 권한을 허용한 뒤, 같은 출처의 다음 페이지로 이동할 때 설정을 복원합니다. 새 탭·브라우저 재시작 등으로 접근 권한이 없으면 아이콘을 다시 누릅니다.
- 목록이 교체되거나 늦게 로드되면 다시 찾아 필터를 적용합니다. 숫자가 바뀌어도 적용한 기준으로 다시 검사합니다. 위치를 찾지 못하는 동안에는 글을 숨기지 않고 기다리며, 계속 실패하면 재선택하세요.
- 기존 버전 사용자는 `chrome://extensions`에서 확장을 새로고침하고 게시판도 새로고침한 뒤 한 번만 다시 설정하세요.

## 페이지별 목록 차이 처리 (v0.1.6)

목록 컨테이너와 숫자 항목에 식별 가능한 클래스가 있으면 이를 우선 저장합니다. 게시글에 썸네일·배지 등이 추가되거나 목록 HTML이 교체돼도 현재 요소를 다시 찾아 적용합니다. 숫자 항목이 없거나 둘 이상으로 모호한 글은 판독 불가로 유지하고, 목록 자체가 둘 이상으로 모호하면 자동으로 고르지 않습니다.

이전 버전 설정은 원래 위치를 찾을 수 있는 페이지에서 자동 보완합니다. 이전 설정으로 위치를 전혀 찾을 수 없다면 해당 페이지에서 범위를 한 번 다시 선택하세요. 클래스로 식별할 수 없는 구조는 순서 기반 탐색을 사용하므로 레이아웃이 달라지면 재선택이 필요할 수 있습니다.

## 범위와 제한

- 선택 영역과 조회수 기준 및 필터 켜짐/꺼짐을 확장 프로그램의 로컬 저장소에 저장하며 같은 게시판의 다음 페이지·새로고침 후 자동 복원합니다.
- 서버에서 받은 데이터의 표시를 필터링합니다. 이미지 다운로드 차단이나 다음 페이지 자동 탐색은 하지 않습니다.
- 하트 조건, 모바일 레이아웃, iframe/사이트 Shadow DOM은 이번 샘플의 지원 검증 범위 밖입니다.
- 정수·쉼표·축약 단위·괄호·숫자 전후의 조회수/댓글수 라벨을 인식합니다. 아래 지원 표기를 참고하세요. 최소값 입력은 정수 또는 쉼표 표기만 사용합니다.
- 숫자를 포함한 HTML 요소와 반복되는 형제 게시글 구조를 사용합니다. 두 개 이상의 숫자를 판독해야 범위를 확정할 수 있습니다. 잘못된 범위는 재선택하세요.
- 사이트 구조에 따라 공지나 특수 행은 판독 불가로 유지될 수 있습니다. 미리보기에서 원하지 않는 항목이 포함됐는지 확인하세요.

## 숫자 표기 지원 (v0.1.7)

| 표기 | 읽는 값 |
| --- | --- |
| `1.3k`, `1.3K`, `1.3천`, `[1.3k]` | 1,300 |
| `1.2만`, `2백만`, `1.5천만`, `2억`, `1.2조` | 각 단위를 정수로 환산 |
| `K/M/B/T` | 천/백만/십억/조 |
| `1만 2천`, `1천3백`, `1억 2,345만 6,789` | 12,000 / 1,300 / 123,456,789 |
| `1,234`, `1 234`, `1’234`, 좁은 공백·줄바꿈 없는 공백 구분 | 1,234 |
| `１．３ｋ`, `［７４］`, `(74)`, `【74】` | 1,300 / 74 / 74 / 74 |
| `👁️ 1.3k`, `💬 [74]`, `조회수 1.3천회`, `댓글 [74]`, `1.3K views`, `Likes: 74` | 라벨을 제외한 숫자 |
| `1,3k`, `1.234,5k` | 1,300 / 1,234,500 |
| `1.3万`, `2.5億`, `١٬٢٣٤` | 13,000 / 250,000,000 / 1,234 |

모든 문자에서 숫자만 뽑아내지는 않습니다. 제목·날짜·시간·퍼센트·금액·여러 지표가 섞인 값은 판독 불가로 유지합니다. `1k+`, `약 1천`, `1천 이상`처럼 정확한 비교값을 정할 수 없는 표기도 임의로 낮은 숫자로 바꿔 숨기지 않습니다.

쉼표 3자리 묶음은 천 단위로 유지합니다(`1,234k` → 1,234,000). 소수 쉼표는 축약 단위 앞에서 소수부가 1~2자리일 때만 허용합니다. `1.234`처럼 소수/천 단위 구분이 모호한 단독 값은 추측하지 않습니다. 사이트가 반올림해 표시한 축약값은 표시값 기준으로 비교하며 숨겨진 원래 숫자는 복구할 수 없습니다.

## 테스트

숫자 파서·확장 실행 경로 테스트: `node --test tests/core.test.js tests/background.test.js`

브라우저 통합 테스트(macOS Chrome 기본 경로): `node tests/browser.test.js`

통합 테스트는 임시 Chrome 프로필에서 실제 DOM에 스크립트를 주입하고, 저장소 API 대역을 사용하여 페이지 이동·새로고침·게시판 격리·해제 상태 복원을 검증합니다. 확장 관리 화면에서 설치하는 과정 자체는 자동 테스트하지 않습니다. 다른 Chrome 실행 파일은 `CHROME_PATH` 환경 변수로 지정할 수 있습니다.

수동 확인은 프로젝트 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/tests/fixture.html`을 여세요. 확장 아이콘을 클릭하고 첫 표의 조회수를 선택합니다.

- 기준 `1,000`: 조건 일치 2개, 숨김 2개, 판독 불가 2개.
- 기준 `0`: 숫자 있는 4개와 판독 불가 2개 모두 유지.
- 기준 `9999`: 일치 0개, 숨김 4개, 판독 불가 2개 및 결과 없음 안내.
- 잘못된 기준, Esc 취소, 반복 적용, 필터 해제, 패널 재열기, 제목 링크·페이지 이동도 확인합니다.

## 구성

`manifest.json` / `background.js`: 사용자 클릭 시 현재 탭에 실행하는 Manifest V3 확장. `activeTab`, `scripting`, `storage` 권한을 사용합니다. 모든 사이트에서 아이콘 클릭으로 임시 접근을 허용해야 실행됩니다.

`open.js`: 아이콘 클릭 시 패널 열기. `core.js`: 숫자 해석, 반복 구조 추출, 게시판 URL 범위 및 저장 위치 복원. `content.js`: 페이지 내 선택 도구·미리보기·필터 패널. 외부 전송이나 원격 코드는 없습니다.
