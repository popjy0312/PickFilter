# PickFilter

페이지에서 조회수 숫자를 직접 선택하고, 최소 조회수 이상인 게시글만 남기는 크롬 확장 프로그램 샘플입니다. FM코리아 `https://www.fmkorea.com/starcraft`를 첫 검증 대상으로 설계했습니다.

## 설치

1. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 프로젝트 폴더를 선택합니다.
3. 게시판을 열고 확장 프로그램 메뉴에서 **PickFilter**를 클릭합니다.

별도 빌드나 패키지 설치는 필요 없습니다. 일반 웹페이지에서 사용하세요. Chrome 내부 페이지 등 실행 불가 페이지에서는 아이콘에 `!`가 표시됩니다.

## 사용

1. **조회수 선택**을 누르고 게시글에 표시된 조회수 숫자를 클릭합니다. Esc로 취소할 수 있습니다.
2. 파란 테두리가 게시글 전체를 감싸는지 확인합니다. 숫자 칸만 선택되거나 너무 넓게 잡혔다면 **범위 넓히기 / 좁히기**로 조정합니다.
3. 미리보기에서 여러 게시글의 조회수가 맞는지 확인하고 **이 범위 확정**을 누릅니다.
4. 최소 조회수(예: `1,000`)를 입력하고 **적용**을 누릅니다. 기준과 같은 조회수도 남깁니다.
5. **필터 해제**로 원래 목록을 복원합니다. 패널을 닫아도 적용된 필터는 유지되며, 확장 아이콘을 다시 누르면 패널이 열립니다.

## 범위와 제한

- 현재 페이지에서 선택 시 확인한 목록에만 적용합니다. 설정은 저장하지 않으며 페이지 이동·새로고침 후 다시 선택합니다.
- 서버에서 받은 데이터의 표시를 필터링합니다. 이미지 다운로드 차단이나 다음 페이지 자동 탐색은 하지 않습니다.
- 하트 조건, 자동 재필터링, 모바일 레이아웃, iframe/사이트 Shadow DOM은 이번 샘플의 지원 검증 범위 밖입니다.
- 조회수는 정수와 쉼표 표기만 지원합니다. 빈 값, 비공개, `1.2만` 등은 판독 불가로 남깁니다.
- 숫자를 포함한 HTML 요소와 반복되는 형제 게시글 구조를 사용합니다. 두 개 이상의 숫자를 판독해야 범위를 확정할 수 있습니다. 잘못된 범위는 재선택하세요.
- 사이트 구조에 따라 공지나 특수 행은 판독 불가로 유지될 수 있습니다. 미리보기에서 원하지 않는 항목이 포함됐는지 확인하세요.
- FM코리아 실제 페이지 조회는 HTTP 429로 차단됐습니다. 실제 HTML 및 실사이트 동작은 미검증이며, 로컬 게시판·카드 fixture에서 검증합니다.

## 테스트

숫자 파서·확장 실행 경로 테스트: `node --test tests/core.test.js tests/background.test.js`

브라우저 통합 테스트(macOS Chrome 기본 경로): `node tests/browser.test.js`

통합 테스트는 임시 Chrome 프로필에서 실제 DOM에 스크립트를 주입해 검증합니다. 확장 관리 화면에서 설치하는 과정 자체는 자동 테스트하지 않습니다. 다른 Chrome 실행 파일은 `CHROME_PATH` 환경 변수로 지정할 수 있습니다.

수동 확인은 프로젝트 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/tests/fixture.html`을 여세요. 확장 아이콘을 클릭하고 첫 표의 조회수를 선택합니다.

- 기준 `1,000`: 조건 일치 2개, 숨김 2개, 판독 불가 2개.
- 기준 `0`: 숫자 있는 4개와 판독 불가 2개 모두 유지.
- 기준 `9999`: 일치 0개, 숨김 4개, 판독 불가 2개 및 결과 없음 안내.
- 잘못된 기준, Esc 취소, 반복 적용, 필터 해제, 패널 재열기, 제목 링크·페이지 이동도 확인합니다.

## 구성

`manifest.json` / `background.js`: 사용자 클릭 시 현재 탭에 실행하는 Manifest V3 확장. `activeTab`, `scripting` 권한만 사용합니다.

`core.js`: 숫자 해석과 반복 구조 추출. `content.js`: 페이지 내 선택 도구·미리보기·필터 패널. 외부 전송이나 원격 코드는 없습니다.
